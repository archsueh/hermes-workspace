
# 英文逻辑命名规则 (English Logical Naming Rules)

## 基本原则
1. **优先使用英文**：所有文件名、目录名、标签优先使用英文
2. **避免乱码**：不使用特殊字符、全角字符、emoji
3. **逻辑结构**：`category_topic_description_version.ext`
4. **日期格式**：YYYYMMDD 或 YYYY-MM-DD
5. **版本控制**：v1, v2, v3 或 _draft, _final, _review

## 命名模板
- 学生论文：`student_thesis_[student_name]_[topic]_[year]_v1.docx`
- 课程大纲：`course_syllabus_[course_code]_[course_name]_[semester]_v1.docx`
- 教学材料：`teaching_[type]_[course]_[topic]_[date]_v1.pptx`
- 研究项目：`research_[project_name]_[type]_[year]_v1.docx`
- 行政表格：`admin_[form_type]_[purpose]_[date]_v1.xlsx`
- 个人资料：`personal_[document_type]_[name]_[date]_v1.pdf`

## 转换规则
1. 中文 → 英文拼音/翻译
2. 长文件名 → 缩写关键信息
3. 日期标准化：YYYYMMDD
4. 版本号统一：v1, v2, v3
5. 空格替换：下划线(_)

## 示例转换
- "201903174005_章颖洁_201903174005_章颖洁_指导记录2.docx"
  → "student_thesis_zhangyingjie_guidance_record_201903_v2.docx"
  
- "2003042700 创意编程基础.docx"
  → "course_syllabus_2003042700_creative_programming_basics_v1.docx"
  
- "设计学院2026届本科毕业论文中期检查.docx"
  → "department_design_college_undergraduate_thesis_midterm_check_2026_v1.docx"
